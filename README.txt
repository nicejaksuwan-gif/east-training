EAST Training & Test System - Random Question Bank 30

Key behavior:
- Question bank: 30 questions.
- Each test attempt randomly selects 10 unique questions.
- Passing score: 8/10 (80%).
- A new test attempt receives a new random set.
- Thai / English switch is supported.
- Video unlock requirement remains 90%.
